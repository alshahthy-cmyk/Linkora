# إدارة الإصدارات المعتمدة في Linkora

يحمي Linkora الوصول إلى خادم الإشارة بطبقتين: رقم بناء أدنى مسموح وتذكرة إصدار موقعة بخوارزمية Ed25519. لا تحتوي حزمة APK أو هذا المستودع على المفتاح الخاص للتوقيع.

## إصدار APK جديد

1. حدّث `expo.version` و`expo.android.versionCode` في `artifacts/mobile/app.json`.
2. استخدم المفتاح الخاص المحفوظ خارج المستودع لتوقيع رقم البناء والإصدار الجديدين، ثم حدّث `artifacts/mobile/lib/release-ticket.ts` بالمعلومات الموقعة.
3. ابنِ APK جديداً واختبره قبل تعطيل الإصدار السابق.
4. شارك APK الجديد يدوياً مع الأشخاص المسموح لهم فقط.
5. في Railway، اضبط `MIN_SUPPORTED_BUILD` إلى رقم البناء الجديد واترك `REQUIRE_RELEASE_TICKET=true`.

لا يوفّر التطبيق رابط تنزيل أو تحديث تلقائياً. أي تطبيق لا يرسل تذكرة صحيحة أو يحمل بناءً أقدم يتلقى خطأً عاماً، بينما يسجل الخادم سبب الرفض الحقيقي داخلياً فقط.

> تذكرة الإصدار تمنع استخدام النسخ القديمة في الاستخدام العائلي المعتاد. لا تمثل تحقّقاً من سلامة التطبيق على مستوى نظام التشغيل ضد مهاجم قادر على تعديل APK.
